## What changed

No change to m365: this release exists because `analytics` fixed a test that failed the kit's tenant-isolation scan, and every plugin here ships at the repository's version.

- Audited against the kit's extended driver-seam guard (kit 0.16.0: no hand-read SQLSTATE, no session state outside a transaction, no `LISTEN`): m365 uses none of them, so it passes unchanged.
- Version stamps only (`rocketflare-plugin.json` and its anchor copy); no code, schema or behaviour change.

## How to apply

1. Run `pnpm plugin upgrade m365 --apply`; it changes only the version stamps.

None.
