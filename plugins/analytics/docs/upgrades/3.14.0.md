## What changed

Analytics imports `react-router` instead of `react-router-dom`, as the kit has since 0.25.0, so it no longer needs the host to keep `react-router-dom` installed (#40).

- `ui/hooks/useDashboardDateFilter.ts`, `ui/pages/DashboardListPage.tsx`, `ui/pages/DashboardViewPage.tsx`, `ui/pages/QueryBuilderPage.tsx` and the `dashboard-view` and `date-filter` UI tests import from `react-router`.
- The other two problems in #40 were the kit's, and kit 0.44.0 fixes them: `pnpm plugin upgrade` no longer writes the `@nivo/heatmap` alias a second time once Biome has wrapped it, and it removes the API prefixes a release dropped from `run_worker_first`.

## How to apply

1. Run `pnpm plugin upgrade analytics --apply`; the six files are the plugin's own and update with it.
2. If `apps/web/vite.config.ts` has the `'@nivo/heatmap'` alias twice (TS1117, left by an upgrade on a kit before 0.44.0), delete one of them.
3. If `"/mcp"` or `"/mcp/*"` appears more than once in `run_worker_first` in `apps/web/wrangler.toml` or `apps/web/wrangler.staging.toml`, keep one of each. The kit has owned `/mcp` since 0.41.0.

## Conflicts to expect

None: the changed files belong to the plugin.

## Verify

1. `grep -rn "react-router-dom" apps/web/src/plugins/analytics` prints nothing.
2. `pnpm plugin check` and `pnpm gate` pass.
