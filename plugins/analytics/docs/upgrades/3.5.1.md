## What changed

`minKit` rises from 0.13.0 to 0.17.1, because before kit 0.17.1 `plugin check` compares dependency ranges as strings and fails analytics as soon as `react-grid-layout` or `react-is` publishes a newer release inside the declared range.

- `pnpm plugin add` runs `pnpm add react-grid-layout@^2.2.4`, and pnpm saves the newest match as `^2.3.0`. Kits before 0.17.1 then report `dependency-range` failures for a range that sits inside the declared one. Kit 0.17.1 keeps the declared range and accepts a range inside it.
- react-grid-layout 2.3.0 (2026-10-05) and react-is 19.3.1 (2026-10-14) turned every install into a kit 0.13.0–0.17.0 copy red, including this repository's CI at the old floor.
- No code, schema or behaviour change.

## How to apply

1. Confirm the kit is 0.17.1 or later (`.rocketflare.json` → `kit.version`); on an older kit, run `pnpm kit:upgrade` first, or stay on analytics 3.5.0.
2. Run `pnpm plugin upgrade analytics --apply`; it changes only the version stamps and `minKit`.

## Conflicts to expect

None.

## Verify

1. `pnpm plugin check` reports `analytics` checks out at the new version, with no `dependency-range` failure.
