## What changed

Analytics' agent guide names the removed `db:refresh-facts` and `db:check-facts` web scripts without a runnable `pnpm` command, so the kit's `/rf-agent-docs` check stops failing in every host that installs it.

- `apps/web/src/plugins/analytics/CLAUDE.md`, "Things that moved and are not coming back": the history note now says "the kit's old `db:refresh-facts` and `db:check-facts` web scripts" instead of `pnpm web db:refresh-facts`, which the check read as a missing script. Docs only; no code, schema or behaviour change.

## How to apply

1. Run `pnpm plugin upgrade analytics --apply`; it updates that one `CLAUDE.md` paragraph and the version stamps.

## Conflicts to expect

None, unless you edited that paragraph of the plugin's `CLAUDE.md` yourself.

## Verify

`pnpm plugin check` passes, and `node .claude/skills/rf-agent-docs/check.mjs` no longer reports `pnpm web db:refresh-facts`.
