## What changed

Guide's `search_guide` tool answers `egress` and `readsContent`, so `pnpm plugin check` no longer warns about it, and the plugin needs kit 0.47.0 or later.

- `egress: false`: it searches the guide index in this database through the app's own embeddings provider.
- `readsContent: false`: it returns passages of the app's own guide pages, which ship with the app and hold no organisation text.
- `minKit` rises from 0.41.0 to 0.47.0, the kit that added the two fields to `Tool`.
- This is the plugin's first release on its own tag, `guide-v3.15.0`. Earlier releases shipped with every plugin under one `X.Y.Z` tag, and `3.14.0` remains a valid pin.

## How to apply

1. On a kit older than 0.47.0, upgrade the kit first (`pnpm kit:upgrade`).
2. Run `pnpm plugin upgrade guide --apply`.

## Conflicts to expect

None: the changed files belong to the plugin.

## Verify

1. `pnpm plugin check --json` reports no `gress:` warning.
