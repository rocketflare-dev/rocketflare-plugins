## What changed

First release of `guide`: an in-app user guide about the app itself, written by the developer's
coding agent and kept in sync with the code by a Claude Code Stop hook.

- Content is the host's: `docs/guide/` (a `guide.config.json` plus markdown pages with
  `audience`, `sources` and `verified` frontmatter), seeded once and never overwritten. The
  `guide` skill builds it into `apps/web/src/host/guide/content.generated.ts`; a config test fails
  the gate while that module is stale.
- `guide.sync` (a daily cron, and a lazy check on every `/api/guide` request) indexes one PLATFORM
  knowledge document per page section — sources `guide:member` and `guide:admin` — and prunes the
  rest. Embeddings are required; without them admins see a banner and search is keyword-only.
- `/guide`: a three-pane reader with search and "Ask the Guide" (AG-UI, `search_guide` only,
  citations as CUSTOM `guide.answer`); a `?` header button and `?` key open Ask from any screen.
  Admin pages are a 404 for members.
- The kit's `search_knowledge` covers the guide for the reader's audience, every agent run gets
  `search_guide`, and a `global-search.providers` contribution adds guide hits to ⌘K when the
  `global-search` plugin is installed.
- The `guide` skill: `/guide init|write|sync|audit`, `guide-build.mjs` and `docs-stale.mjs`.

## How to apply

1. Install with `pnpm plugin add https://github.com/rocketflare-dev/rocketflare-plugins.git@<version> --subdir plugins/guide --apply`
   on a kit at 0.31.0 or later (the release that added platform `searchKnowledge` sources and
   `hostFiles`). No `db:generate`: the plugin has no table.
2. Run `/guide init` so the coding agent writes the guide from this app's code, then
   `node .claude/skills/guide/scripts/guide-build.mjs` and commit `docs/guide/`,
   `apps/web/src/host/guide/` and `apps/web/public/guide/`.
3. Configure embeddings (an `EMBEDDINGS_API_KEY` or the `[ai]` binding) so the guide's index builds.

## Conflicts to expect

None: a first install. `docs/guide/` and `apps/web/src/host/guide/` are seeded only when absent.

## Verify

`pnpm gate` passes; `/guide` shows the starter pages; as an admin with embeddings configured, the
banner clears within a minute of the first visit and a search for a paraphrase finds its page.
